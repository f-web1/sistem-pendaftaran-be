# 🛠️ Sistem Pendaftaran Mahasiswa Baru Berbasis Web (Backend)

Repositori ini merupakan bagian **Backend API** dari tugas pengembangan aplikasi web sistem pendaftaran mahasiswa baru.

## 👥 Informasi Kelompok 3
* **UI/UX:** Fanzhi Sukma
* **Frontend:** Fahri Ahmad Subhakti
* **Backend:** Tajul Fazarie

## 🛠️ Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js

## ⚙️ Cara Menjalankan Proyek
1. Clone repositori ini.
2. Jalankan perintah `npm install` untuk memasang semua dependencies.
3. Jalankan `npm start` atau `npm run dev` untuk menjalankan server backend pada port `5000`.
